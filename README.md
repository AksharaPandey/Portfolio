## 📌 About

This is a **3D interactive developer portfolio** built using **React JS** and **Three.js**. It showcases my technical skills, featured projects, and resume in an engaging 3D environment, offering a unique way for visitors to explore my work.

## 🚀 Features

- 🌟 Interactive 3D elements with Three.js
- 💻 Responsive design across devices
- 📂 Project showcase with live links
- 🧠 About Me and Skills section
- 📄 Downloadable Resume
- 🌙 Dark mode toggle

## 🛠️ Tech Stack

- **Frontend:** React JS
- **3D Graphics:** Three.js (via @react-three/fiber and drei)
- **Styling:** Tailwind CSS / Styled-components (if used)
- **Deployment:** Vercel / Netlify / GitHub Pages
